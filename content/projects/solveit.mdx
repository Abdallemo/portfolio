I noticed that student communities often use WhatsApp or Discord to ask for academic help, but it's hard to track tasks and payments aren't always secure. I wanted to try building a centralized place where this could happen more professionally.

### Why I built this
I wanted to solve the friction in peer-to-peer help. By making a dedicated dashboard, students can post what they need help with, and others can bid to mentor them.

### How it works
- **Next.js & Tailwind**: The main interface is built with Next.js. I kept the design clean so it's easy to use.
- **Go for Real-time**: I used a small Go service to handle the chat and notifications because Go's goroutines make it really easy to manage multiple concurrent WebSocket connections without much lag.
- **AI Categorization**: I integrated OpenAI to help sort the tasks. It just reads the student's description and suggests the subject so I don't have to categorize everything manually.
- **Payments**: Since this involves money, I used Stripe to handle the transactions securely.

### A technical challenge
One of the trickiest parts was the real-time chat. I had to learn how to keep the student and mentor in sync without the page refreshing. Using Go's "Hub" pattern for WebSockets was a great learning experience.

```go
// A look at the Hub pattern I used for chat
func (h *Hub) HandleConnection(conn *websocket.Conn, userID string) {
    client := &Client{
        hub:    h,
        conn:   conn,
        send:   make(chan []byte, 256),
        userID: userID,
    }
    h.register <- client
    go client.writePump()
    go client.readPump()
}
```

### Things I learned
I struggled with database performance as I added more features. I realized that just adding fields to PostgreSQL wasn't enough; I had to learn about indexing on things like `mentorId` to keep the queries fast. It made me realize how important database design is even for hobby projects.

### What's next
I'm thinking about adding video chat using WebRTC so mentors can explain things better, and maybe more detailed analytics for the dashboard.
