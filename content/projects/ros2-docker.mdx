A developer tool that simplifies the setup and deployment of ROS2 (Robot Operating System 2) environments using Docker containers.

### Why I built this
ROS2 installation can be painful and inconsistent across systems. This tool provides a reproducible, isolated environment that just works.

### Features
- **X11 Forwarding**: Run GUI-based ROS2 tools (like RViz2 or Gazebo) directly from the container.
- **Persistent Storage**: Maps local source folders to the container.
- **Global Access**: Simple installation as a global CLI tool.
