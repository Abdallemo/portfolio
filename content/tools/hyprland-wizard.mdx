A complete customization tool for Hyprland on Arch-based and Ubuntu distributions.

### Features
- One-click Hyprland configuration.
- Pre-configured settings for optimal workflow.
- Automated dependency checks and installation.
- Integrated setup for Kitty terminal.

This was built to make the transition to a tiling window manager as seamless as possible, handling all the complex configuration out of the box.
